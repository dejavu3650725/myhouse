# 🏠 프롬프트로 마이 하우스 제작

초등 실과 **[6실05-02] 컴퓨터에게 명령하는 방법을 체험하고, 주어진 문제를 해결하는 프로그램을 작성한다**
성취기준을 위한 생성형 AI 체험·비판적 리터러시 수업 도구입니다.

손글씨로 쓴 명령을 AI가 읽고 → 3D 방 설계도를 만들고 → 학생이 결과를 따져 보고 →
명령을 고쳐 다시 만들고 → 직접 가구를 옮겨 완성합니다.

---

## 🚀 전시회 준비 (권장 순서)

### 1단계 · 깃허브에 올리기

**`깃허브에 올리기.bat`** 을 더블클릭하세요.
처음이라면 로그인 창이 뜹니다. 브라우저에서 승인하면 끝입니다.

### 2단계 · GitHub Pages 켜기

<https://github.com/dejavu3650725/myhouse> → **Settings → Pages**
→ Branch 를 **`main` / `(root)`** 로 지정 → Save

1~2분 뒤 아래 주소가 열립니다.

```
https://dejavu3650725.github.io/myhouse/
```

### 3단계 · 폰으로 체험시키기

앱 헤더의 **[📱 내 폰으로 열기]** → 주소칸에 위 Pages 주소를 넣으면 QR이 만들어집니다.
참가자가 폰으로 QR을 찍어 열고 **[📷 지금 사진 찍기]** 로 스케치를 바로 올립니다.

> Pages 주소는 `https://` 라서 폰 카메라·AI 연결이 모두 정상 동작합니다.
> 이게 전시회에서 가장 확실한 방법입니다.

---

## 🔑 API 키

<https://aistudio.google.com/apikey> 에서 Gemini API 키를 무료로 발급받으세요.

- **공개된 Pages 주소에서는** 앱 안 **[⚙️ 교사 설정]** 에 키를 한 번 입력합니다.
  브라우저에 저장되므로 그 기기에서는 다시 입력할 필요가 없습니다.
- **내 PC에서만 쓸 때는** `config.local.js` 파일에 키를 적어 두면 열 때마다 자동으로 채워집니다.

```js
window.MH_API_KEY = "AIza...여기에 실제 키...";
```

> ⚠️ `config.local.js` 와 `.env` 는 `.gitignore` 에 등록되어 **깃허브에 올라가지 않습니다.**
> 브라우저에서만 도는 정적 페이지는 키를 숨길 방법이 없으니,
> 공개 주소에 키를 심지 마세요.

## 💻 인터넷 없이 / 내 PC에서만 쓰기

**`실행하기.bat`** 을 더블클릭하면 로컬 서버가 켜지고 <http://localhost:8000> 이 열립니다.
(파이썬이 설치되어 있어야 합니다. 없으면 깃허브 Pages 방식을 쓰세요.)

`index.html` 을 그냥 더블클릭해도 화면은 보이지만, 브라우저 보안 정책 때문에
**AI 연결이 막힐 수 있습니다.**

## 📚 수업 흐름

| 단계 | 활동 |
|---|---|
| ① 손글씨 | 종이에 방을 주문하는 명령을 쓰고 촬영해 업로드 |
| ② AI가 짓기 | AI가 설계도(JSON)를 만들고 앱이 3D 방으로 조립 |
| ③ 따져보기 | 다섯 가지 눈 체크리스트 + 겹침·통로 자동 검사 |
| ④ 명령 도우미 | 방 크기·가구·자리·색·약속을 골라 정확한 명령 문장 조립 |
| ⑤ 완성 | 가구를 끌어 배치하고 기념 카드(PNG) 저장 |

가구는 **44종**(침실·거실·공부방·주방·욕실·놀이취미·문꾸미기)이며
게임기·오락기·피아노·농구골대·로봇 등도 만들 수 있습니다.

## 📁 파일 설명

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 본체. 이 파일 하나에 전부 들어 있습니다. |
| `깃허브에 올리기.bat` | init·commit·push 를 한 번에 실행 |
| `실행하기.bat` | 내 PC에서만 쓸 때 로컬 서버 실행 |
| `config.local.js` | 내 PC용 API 키 (커밋 안 됨) |
| `.env` | 참고용 키 메모 (커밋 안 됨) |
| `.gitignore` | 키 파일이 올라가지 않도록 막아 줌 |
